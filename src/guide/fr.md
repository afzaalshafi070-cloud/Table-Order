# Table Order — Guide d'utilisation

Ce guide explique chaque partie de l'application. Ouvrez **Paramètres** et choisissez une section dans la barre supérieure pour modifier cette partie de votre restaurant.

## Langue

Choisissez la langue de l'application dans **Langue**. La caisse et le menu client changent immédiatement sur cet appareil. L'arabe, l'ourdou, le persan et le pachto affichent la page de droite à gauche.

## Restaurant

Renseignez le nom du restaurant, sa description, son adresse, le téléphone de contact, les horaires d'ouverture et le libellé de la devise.

## Image de marque

Importez votre logo dans **Logo et thème**. Les couleurs et la police d'affichage sont automatiquement déduites du logo, pour la caisse et le menu client.

## Succursales

Gérez les emplacements de vos succursales. Le nom affiché aux clients reste le même. Pour ajouter un nouvel emplacement physique, envoyez une demande ; l'administrateur l'approuve. Vous n'avez pas besoin d'un nouveau code d'activation.

## Paiement

Activez le paiement en espèces et/ou le paiement en ligne. Le paiement en ligne est un moyen manuel (par exemple JazzCash, Easypaisa ou un QR bancaire) : vous saisissez le nom du moyen, le titulaire du compte et les instructions, puis vous importez une image de QR de paiement. Les clients scannent le QR et effectuent eux-mêmes le virement. Ce n'est pas une passerelle de paiement.

## Abonnement

Consultez les détails de votre abonnement et de son renouvellement.

## Sécurité

Modifiez le code PIN de connexion du restaurant. Saisissez le PIN actuel, puis le nouveau PIN (4 à 6 chiffres), et confirmez-le. Le PIN est enregistré sous forme hachée.

## Taxes

Configurez les paramètres de taxe de votre restaurant. Vérifiez les valeurs avec votre comptable avant de les modifier.

## Livraison

Gérez ici les zones de livraison. Les livreurs n'ont pas besoin de code QR. Un lien permanent vers l'application livreur est créé depuis la caisse.

## Alertes

Choisissez le son et la vibration des nouvelles commandes, et activez ou désactivez les alertes de commande, de demande d'eau et d'appel serveur. Ces préférences sont enregistrées sur cet appareil.

## Impression

Définissez les options du reçu : afficher la taxe, afficher le logo (si pris en charge) et le message de pied de page.

## WhatsApp

Facultatif. Enregistrez un numéro WhatsApp et un bouton WhatsApp apparaît sur le menu client.

## Service

Clôturez le service et imprimez le rapport de fin de journée (EOD), ou déconnectez-vous de cet appareil.

## Promo

Créez et gérez les promotions pour vos clients.

## NTN / STRN

Saisissez vos numéros d'enregistrement fiscal NTN et STRN pour la facture.

## Guide d'utilisation

Cette page. Elle affiche toujours le guide dans la langue que vous avez choisie pour l'application.
